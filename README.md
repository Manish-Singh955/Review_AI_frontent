# ReviewAI Frontend

React and Vite frontend for the ReviewAI / Scanrly application.

## Setup

```sh
npm install
```

Copy `.env.example` to `.env` and set `VITE_API_URL` to the backend API URL. Set `VITE_PUBLIC_APP_URL` to the public frontend URL before generating production QR codes.

## Run

```sh
npm run dev
npm run build
```
